UI Polish Opportunities for App Store Screenshots

Based on competitive research (Fitbod, Hevy, Strong, Slate) and your current implementation. Click areas you're most interested in improving.

1

Home Screen: Workout Card Visual Upgrade

Your workout card is functional but flat. Top apps use subtle gradients, glow effects, or card depth to make the primary CTA card feel alive. Adding a faint amber glow behind the "Start Workout" button and a gradient border on the card would make the Home screen screenshot-ready. The greeting could also show the user's first name in amber (it currently shows as primary white).

Current: Flat surface card, plain button
Proposed: Gradient border card, glowing CTA, amber name accent
2

Session: Progress Bar & Set Completion Polish

The exercise progress indicator (segmented capsules) could feel more rewarding. Top apps like Strong use animated fill transitions when completing a set. Adding a subtle scale bounce + haptic when tapping the checkmark, and a smooth amber fill animation on the progress bar segments, would make sessions feel premium.

Current: Instant state change on set complete
Proposed: Spring animation + haptic feedback + progress bar fill animation
3

Coach Chat: Richer Message Bubbles

The coach chat is functional but looks like a basic chat. Premium AI apps (ChatGPT, Copilot) use markdown rendering, code blocks, and styled cards in AI responses. Adding bullet-point formatting, bold emphasis, and possibly small inline exercise cards when Hone mentions an exercise would make the Coach screenshot stand out.

Current: Plain text bubbles
Proposed: Markdown-rendered bubbles with formatted lists, bold, exercise mini-cards
4

Session Summary: Celebration Moment

The summary screen is clean but misses the dopamine hit. Apps like Strava and Nike Run Club use confetti, animated counters, and bold congratulatory copy. A brief confetti burst on PR achievements, animated number counters for stats, and a more energetic heading ("Crushed it!" instead of "Great work.") would make this screenshot-worthy.

Current: Static checkmark + stats
Proposed: Confetti on PR, animated counters, dynamic heading
5

Onboarding: Visual Delight & Illustrations

The onboarding cards are text + radio chips. Top apps use custom illustrations or SF Symbol animations on each card to make the setup feel premium. Adding large animated icons (e.g., dumbbell for equipment, calendar for days, target for goals) above each card's heading would dramatically improve first impressions.

Current: Text heading + chip options
Proposed: Animated SF Symbol hero + heading + styled chips
6

Tab Bar: Custom Styling

The default iOS tab bar works but doesn't feel branded. A floating pill-style tab bar or simply adding a subtle top border and ensuring the amber tint pops against the dark background would make every screenshot feel more polished. Some apps also add a subtle blur effect to the tab bar background.

Current: Default iOS tab bar
Proposed: Branded tab bar with blur, amber active tint, subtle top border
