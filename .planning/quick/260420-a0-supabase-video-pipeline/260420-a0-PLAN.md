# Quick Task 260420-a0: Supabase Storage Video Pipeline

## Context

2,462 MP4 videos in `videos/VERTICAL VIDEOS/` organized by muscle group. App needs to stream exercise videos via AVPlayer. Stack uses Supabase Storage for video hosting. The exercises table currently has a `mux_playback_id` column (all NULL) — we add a `video_url` column alongside it to store Supabase Storage public URLs (keeps Mux migration path open).

## Video Structure

- 12 muscle group folders: Abdominals, Back, Biceps, Calisthenics-Cardio-Plyo-Functional, Chest, Forearms, Legs, Powerlifting, Shoulders, Stretching - Mobility, Triceps, Yoga
- 213 `_female`/`_Female` suffix variants, 1758 standard videos
- Deduplication: strip `_female`/`_Female` from exercise name; if both exist, prefer non-female video URL

### Task 2: Node.js Upload Script

**Files:**
- `scripts/upload-videos.mjs` (create)
- `scripts/README.md` (create — usage instructions)

**Action:**
Write an ES module script that:
1. Reads `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` from environment (or `.env` file via `--env-file` flag with Node 20.6+)
2. Creates `exercise-videos` storage bucket if it doesn't exist (public: true)
3. Walks `videos/VERTICAL VIDEOS/` directory recursively
4. For each `.mp4` file:
   - Derives `primaryMuscle` from folder name using the mapping table above
   - Derives `equipmentTag` from filename keywords using the mapping table above
   - Strips `_female`/`_Female` suffix from filename to get the canonical exercise name
   - Uploads file to Supabase Storage at path `exercise-videos/{folder}/{filename}`
   - Gets the public URL back
5. Deduplicates: for exercises where both standard and female variants exist, prefers the standard (non-female) video URL
6. Upserts each exercise into `public.exercises` via `supabase.from('exercises').upsert()` with conflict on `name`
7. Prints progress (file count, current file) and a final summary (inserted, updated, skipped, errors)

**Script signature:**
```
node scripts/upload-videos.mjs \
  --videos-dir ./videos/VERTICAL\ VIDEOS \
  --supabase-url $SUPABASE_URL \
  --supabase-key $SUPABASE_SERVICE_ROLE_KEY
```
Or reads from environment if flags not provided.

**Dependencies:** `@supabase/supabase-js` (already in package.json or add to a scripts/package.json)

**Error handling:**
- Skip files that fail upload (log error, continue)
- Print final count of errors
- Dry-run mode with `--dry-run` flag (logs what would be done, no uploads)

**Verify:** Script exists, `--dry-run` flag works, handles missing env vars gracefully.

**Done:** Script committed.
