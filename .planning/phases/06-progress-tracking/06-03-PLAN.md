**NotificationScheduler.swift** — Create at `WorkoutApp/Core/Notifications/NotificationScheduler.swift`:

```swift
import Foundation
import UserNotifications
import CoreData
```

Class: `@MainActor final class NotificationScheduler` (no `@Observable` — no published UI state).

Init: `init(context: NSManagedObjectContext? = nil)` — defaults to `PersistenceController.shared.container.viewContext`.

**Methods:**

1. **`func requestPermissionIfNeeded() async`** — Check `UNUserNotificationCenter.current().notificationSettings()`. If `.authorizationStatus == .notDetermined`, call `requestAuthorization(options: [.alert, .sound])`. Per D-24: called after first session completes (earned moment). Safe to call multiple times — system won't re-prompt.

2. **`func scheduleWorkoutReminders(planDays: [(weekday: Int, workoutType: String)], currentStreak: Int) async`** — First cancel all existing workout reminders via `cancelAllWorkoutReminders()`. Then for each planDay: check `hasLoggedSessionToday()` only matters at scheduling time (repeating trigger handles future days). Create notification:
   - Identifier: `"workout-reminder-\(weekday)"` (allows cancel/replace per weekday)
   - DateComponents: `weekday = planDay.weekday`, `hour = 19`, `minute = 0`, `timeZone = TimeZone.current` (CRITICAL per Pitfall 1)
   - Content: If `currentStreak >= 3`: title = `"\(workoutType) day is waiting"`, body = `"You're on a \(currentStreak)-day streak — keep it going!"` (per D-23). Else: title = `"Ready for your \(workoutType) day?"`, body = `"Your plan is waiting."` (per D-22).
   - Sound: `.default`
   - Trigger: `UNCalendarNotificationTrigger(dateMatching: components, repeats: true)`
   - Add via `try await UNUserNotificationCenter.current().add(request)`

3. **`func cancelAllWorkoutReminders() async`** — Get pending requests via `UNUserNotificationCenter.current().pendingNotificationRequests()`. Filter identifiers with prefix `"workout-reminder-"`. Remove them via `removePendingNotificationRequests(withIdentifiers:)`. Do NOT remove rest-timer notifications (they use different identifiers).

4. **`func hasLoggedSessionToday(userId: String) -> Bool`** — NSFetchRequest on CDSessionLog. Predicate: `completedAt >= %@ AND completedAt < %@ AND userId == %@` where the two dates are today's start-of-day and tomorrow's start-of-day via `Calendar.current.startOfDay(for: Date())`. FetchLimit: 1. Return `!results.isEmpty`. Per D-25.

5. **`func shouldScheduleNotifications() async -> Bool`** — Check if notification authorization is `.authorized`. Return false if `.denied` or `.notDetermined`.

Error handling: all methods wrap in do/catch with `print("NotificationScheduler: [method] failed: \(error)")`. Non-fatal — notification failure should never crash the app.

```xml
<string>We'll remind you when it's time for your next workout to help you stay on track.</string>
```
