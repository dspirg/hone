struct WeekKey: Hashable, Comparable {
    let year: Int
    let week: Int
    static func < (lhs: WeekKey, rhs: WeekKey) -> Bool {
        (lhs.year, lhs.week) < (rhs.year, rhs.week)
    }
}

**ProgressViewModel.swift** — Create `@Observable @MainActor final class ProgressViewModel`:

Init pattern: `init(context: NSManagedObjectContext? = nil)` — defaults to `PersistenceController.shared.container.viewContext`. Store as `private let viewContext`.

Published state properties:
- `var sessions: [CDSessionLog] = []`
- `var currentStreak: Int = 0`
- `var longestStreak: Int = 0`
- `var weeklyCompleted: Int = 0`
- `var weeklyPlanned: Int = 0`
- `var weekBuckets: [WeekBucket] = []`
- `var isLoading: Bool = false`
- `var loadError: String? = nil`
- `private var cachedUserId: String?`

Methods:

1. **`func onAppear(appState: AppState)`** — Cache `appState.currentUser?.id.uuidString` into `cachedUserId`. Call `Task { await loadProgress() }`.

2. **`func loadProgress()`** — Set `isLoading = true`, `defer { isLoading = false }`. Fetch all completed sessions via `fetchCompletedSessions()`. Then call `computeStreak()`, `computeWeeklyRing()`, `computeWeekBuckets()`. On catch: set `loadError = "Couldn't load your progress. Pull down to try again."`.

3. **`func fetchCompletedSessions() throws -> [CDSessionLog]`** — NSFetchRequest on CDSessionLog. Predicate: `NSPredicate(format: "completedAt != nil AND userId == %@", cachedUserId ?? "")`. Sort: `NSSortDescriptor(key: "completedAt", ascending: false)`. Return fetched results. Per T-06-01: always include userId predicate.

4. **`func computeStreak(from sessions: [CDSessionLog])`** — Extract unique calendar days from `completedAt` dates using `Calendar.current.startOfDay(for:)`. Deduplicate with `Set()`. Sort descending. Walk the sorted dates: if consecutive calendar days (diff == 1), increment streak. If first date is not today or yesterday, current streak = 0. Track both current and longest. Set `self.currentStreak` and `self.longestStreak`.

5. **`func computeWeeklyRing(from sessions: [CDSessionLog])`** — Get current calendar week's start via `Calendar.current.dateInterval(of: .weekOfYear, for: Date())`. Count sessions with `completedAt` in that interval. Set `weeklyCompleted`. For `weeklyPlanned`: read from active plan's workout days count if available, default to 4.

6. **`func computeWeekBuckets(from sessions: [CDSessionLog]) -> [WeekBucket]`** — Filter to last 8 weeks using `Calendar.current.date(byAdding: .weekOfYear, value: -8, to: Date())`. Group by `(yearForWeekOfYear, weekOfYear)`. For each bucket: count sessions, sum volume as `Int(session.totalSets) * Int(session.totalReps)`. Format week label as "MMM d" of the Monday of that week. Sort ascending by WeekKey. Set `self.weekBuckets`.

7. **`func detectPRs(for sessionLog: CDSessionLog) throws -> [PRResult]`** — Get current session's CDSetLog records via `(sessionLog.setLogs?.array as? [CDSetLog]) ?? []`. Group by `exerciseName`, find max `repsLogged` per exercise. For each exercise: fetch all prior CDSetLog records with same exerciseName AND `sessionId != sessionLog.id` AND `userId == cachedUserId`. Find prior max. If current max > prior max, create PRResult. Return array.

8. **Testing helper**: `func setUserIdForTesting(_ userId: String) { cachedUserId = userId }`

Error handling: non-fatal print + leave state as empty arrays (view shows empty state). Pattern: `print("ProgressViewModel: [method] failed: \(error)")`.
