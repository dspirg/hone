# Phase 6 — UI Design Contract

> Visual and interaction contract for Phase 6: Progress Tracking.
> Generated by gsd-ui-researcher, verified by gsd-ui-checker.

## Design System

| Property | Value |
|----------|-------|

## Spacing Scale

Declared values (multiples of 4, matching all prior phases):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | VStack spacing within stat cells, badge internal gaps |
| sm | 8pt | Between heading and subtitle, row internal element gaps, PRBadgeView vertical padding |
| md | 16pt | Default horizontal page padding, card internal padding, PRBadgeView horizontal padding |
| lg | 24pt | Between major section breaks within ProgressView |
| xl | 32pt | Between streak block and session history section |
| 2xl | 48pt | Top breathing room above streak display |
| 3xl | 64pt | Not used in this phase |

Exceptions:
- Touch targets for session history rows: minimum 44pt height (Apple HIG)
- Weekly ring: 120pt diameter (fixed, not from scale — visual balance with streak number)
- PR badge height: 52pt (matches Done button height from Phase 4 SessionSummaryView)

Source: existing pattern from HomeView (VStack spacing: 16), SessionSummaryView (spacing: 32, padding: 16).

## Typography

SwiftUI semantic font scale — no custom sizes. These map to the existing codebase pattern.

Exactly 4 size tokens, exactly 2 weights:

| Role | SwiftUI Token | Approx pt | Weight | Line Height |
|------|--------------|-----------|--------|-------------|
| Display | `.largeTitle` | 34pt | `.semibold` (600) | 1.2 |
| Heading | `.title2` | 22pt | `.semibold` (600) | 1.2 |
| Body | `.body` | 17pt | `.regular` (400) | 1.5 |
| Caption | `.caption` | 12pt | `.regular` (400) | 1.3 |

**Specific assignments for this phase:**

| Element | Token | Weight |
|---------|-------|--------|
| Streak number (e.g. "12") | `.largeTitle` | `.semibold` |
| Streak label ("day streak") | `.caption` | `.regular` |
| Weekly ring fraction ("3/4") | `.title2` | `.semibold` |
| Weekly ring label ("this week") | `.caption` | `.regular` |
| Section headers ("Recent Sessions", "Volume", "PRs") | `.title2` | `.semibold` |
| Session history row — workout name | `.body` | `.semibold` |
| Session history row — metadata (date, exercise count, sets) | `.caption` | `.regular` |
| Chart axis labels | `.caption` | `.regular` |
| PR badge — exercise name | `.body` | `.semibold` |
| PR badge — new record value | `.title2` | `.semibold` |
| PR badge — previous best | `.caption` | `.regular` |

Note: `.subheadline` and `.bold` are not used in this phase. `.largeTitle.semibold` with `AccentColor` foreground provides sufficient visual dominance for the streak number without requiring `.bold`. Session row metadata formerly assigned `.subheadline` is now `.caption` — the size difference is minimal and reduces the token count to the required maximum of 4.

Source: existing pattern from HomeView (`.title2.weight(.semibold)`, `.body`), SessionSummaryView (`StatCell` uses `.title2.weight(.semibold)` + `.body`).

## Color

Named color assets — all pre-existing in `Assets.xcassets`. No new color assets required for this phase.

| Role | Asset Name | Light Mode | Dark Mode | Usage |
|------|-----------|------------|-----------|-------|
| Dominant (60%) | `AppBackground` | #F5F5F5 (R:0.961 G:0.961 B:0.961) | #0F0F0F (R:0.059 G:0.059 B:0.059) | ProgressView background, ScrollView background |
| Secondary (30%) | `CardBackground` | #FFFFFF | #1C1C1C (R:0.110 G:0.110 B:0.118) | Streak card, session history rows, chart containers |
| Accent (10%) | `AccentColor` | #FF6B35 (R:1.0 G:0.420 B:0.208) | same | Specific elements only (see below) |
| Destructive | `.red` (system) | system red | system red | Not used in this phase — no destructive actions |
| Secondary label | `.secondary` (system) | system gray | system gray | Metadata text, chart axis, session row subtitles |

**Accent reserved for (explicit list):**
1. Streak number digit(s) — the primary motivational number
2. Weekly completion ring fill stroke
3. Active tab bar icon (`.tint(Color("AccentColor"))` — inherited from MainTabView, not set per-tab)
4. PR badge background tint (10% opacity AccentColor fill behind the badge text)

Accent is NOT used for: chart bars/lines, section headers, navigation titles, session row backgrounds, or general body text.

**Chart color:**
- Sessions/week bar chart bars: `.secondary` foreground color (system adaptive gray) — keeps charts informational, not decorative
- Volume line chart line: `AccentColor` at 70% opacity — single accent use permitted because the line is the primary data signal

Source: color values read directly from `Assets.xcassets` color set JSON. Pattern confirmed in `MainTabView.swift`, `SessionSummaryView.swift`, `ChatBubbleView.swift`.

## Component Inventory

New components required for this phase:

### ProgressView (root tab view)
- `NavigationStack` root
- `ScrollView` with `VStack(spacing: 24)` sections
- Navigation title: "Progress" (`.navigationBarTitleDisplayMode(.large)`)

### StreakCard
- `VStack(spacing: 8)` inside `CardBackground` rounded card
- Streak number: `.largeTitle.weight(.semibold)`, `AccentColor` foreground
- Label: "day streak" — `.caption`, `.secondary` foreground
- Card: `.padding(16)`, `.background(Color("CardBackground"))`, `.clipShape(RoundedRectangle(cornerRadius: 16))`

### WeeklyRingView
- Custom `Circle` / `trim` shape drawn with SwiftUI
- Ring diameter: 120pt fixed
- Background ring: `.secondary` at 20% opacity, stroke 10pt
- Fill ring: `AccentColor`, stroke 10pt, trim from 0 to `completedDays/plannedDays`
- Center text: fraction (e.g. "3/4") in `.title2.weight(.semibold)`, label "this week" in `.caption.regular` below
- Inline with StreakCard in an `HStack(spacing: 24)`

### SessionHistoryRow
- `HStack` with 44pt minimum height
- Leading: workout name (`.body.semibold`) stacked above date + counts (`.caption`, `.secondary`)
- Trailing: chevron SF Symbol (`chevron.right`, `.caption`, `.secondary`)
- Tap: push `SessionDetailView` via `NavigationLink`
- Divider between rows: system `Divider()` (no custom color)

### SessionDetailView
- `NavigationStack` child pushed from history row
- Lists each exercise with logged sets and reps
- Uses same `CardBackground` + `md` padding pattern

### ChartSectionView (two instances)
- Container: `CardBackground` card, `.padding(16)`, `cornerRadius(16)`
- Section label above chart: `.title2.weight(.semibold)`
- Time range label: "Last 8 weeks" — `.caption`, `.secondary`, trailing aligned

#### Sessions/Week Bar Chart
- `Chart { BarMark(x: .value("Week", week), y: .value("Sessions", count)) }`
- Bar foreground: `.secondary` (system adaptive)
- Chart height: 160pt fixed
- X-axis: week label (abbreviated, e.g. "Apr 7") — `.caption`
- Y-axis: integer session count — `.caption`

#### Volume Line Chart
- `Chart { LineMark(x: .value("Week", week), y: .value("Volume", volume)) }`
- Line foreground: `AccentColor` at 70% opacity
- Area fill: `AccentColor` at 10% opacity (using `.chartPlotStyle`)
- Chart height: 160pt fixed
- X-axis: week label — `.caption`
- Y-axis: abbreviated volume (e.g. "1.2k") — `.caption`

### PRBadgeView (injected into SessionSummaryView)
- Appears below existing stats block in `SessionSummaryView` when PR(s) detected
- Container: `HStack(spacing: 8)` with `AccentColor` at 10% opacity background fill
- Padding: 8pt vertical (sm), 16pt horizontal (md)
- Corner radius: 12pt
- Leading: `trophy.fill` SF Symbol, `AccentColor`
- Body: exercise name (`.body.semibold`) + "New record: X reps" (`.body`, `.primary`) + "Previous best: Y reps" (`.caption`, `.secondary`)
- No animation, no haptic (D-16: understated, non-gamified)
- If multiple PRs in session: `VStack(spacing: 8)` of individual `PRBadgeView` rows

## Interaction Contract

| Interaction | Behavior |
|-------------|----------|
| Tap session history row | Push `SessionDetailView` via `NavigationLink` |
| Session detail back | System back button (NavigationStack pop) |
| Charts — tap bar/point | Static display only — no tap-to-detail in v1 (Claude's discretion: keep simple) |
| Streak display | Read-only — no tap action |
| Weekly ring | Read-only — no tap action |
| PR badge | Read-only — appears in completion flow, no tap action |
| Notification permission prompt | System `UNUserNotificationCenter.requestAuthorization` alert — no custom UI |

## Copywriting Contract

| Element | Copy |
|---------|------|
| Tab label | "Progress" |
| Navigation title | "Progress" |
| Streak label | "{N} day streak" (singular "day" when N=1: "1 day streak") |
| Weekly ring label | "this week" |
| Section: history | "Recent Sessions" |
| Section: charts | "Activity" |
| Section: volume chart | "Volume" |
| Primary CTA | No primary CTA in this view — it is an information display tab |
| Empty state heading (no sessions logged) | "No sessions yet" |
| Empty state body | "Complete your first workout to start tracking progress." |
| Empty state CTA | "Go to Train" (button — navigates to Train tab) |
| Streak zero state | "Start your streak today" (shown in place of "0 day streak") |
| Weekly ring zero state | "0/{N} this week" with ring at 0% fill |
| Chart empty state | "No data yet" in `.secondary` centered in chart frame |
| Error state (data load failure) | "Couldn't load your progress. Pull down to try again." |
| PR badge | "New Record" (section label above badges) |
| PR badge body | "{Exercise Name} — {N} reps" |
| PR badge subtext | "Previous best: {N} reps" |
| Notification (no streak) | "Ready for your {Workout Type} day? Your plan is waiting." |
| Notification (streak >= 3) | "{Workout Type} day is waiting — you're on a {N}-day streak!" |

No destructive actions in this phase. No confirmation dialogs required.

Source: D-07 (streak prominence), D-15 (PR badge content), D-22/D-23 (notification copy), CONTEXT.md specifics.
