<objective>
Fix RevenueCat webhook payload parsing (Gap 1 / CR-02).

Purpose: The webhook reads `event.app_user_id` from the flat outer JSON object, but RevenueCat sends a nested payload `{ api_version, event: { type, app_user_id, id } }`. This means `app_user_id` is always `undefined`, every real event is rejected by the anonymous-ID guard, and `profiles.subscription_status` is never updated. This breaks D-19 (server-side subscription authority).

Output: Corrected webhook that parses the nested `event` object and reads `app_user_id`, `type`, and `id` from `payload.event.*`.
</objective>

  return new Response("Missing event object", { status: 400 })
}

const appUserId: string = rcEvent.app_user_id
const eventType: string = rcEvent.type
const eventId: string = rcEvent.id
