  <action>
Create a StoreKit Configuration file for Xcode local testing (File > New > File > StoreKit Configuration File). This enables sandbox purchase testing without requiring App Store Connect product approval.

Configure two subscription products in the StoreKit Configuration file:

1. **Monthly product**:
   - Product ID: `com.workoutapp.pro.monthly`
   - Type: Auto-Renewable Subscription
   - Reference Name: "Pro Monthly"
   - Price: $9.99
   - Subscription Group: "WorkoutApp Pro"
   - Introductory Offer: Free trial, 14 days (D-03)
   - Promotional Offer: ID `monthly_50pct_3months`, Pay-as-you-go, $4.99/month, 3 months

2. **Annual product**:
   - Product ID: `com.workoutapp.pro.annual`
   - Type: Auto-Renewable Subscription
   - Reference Name: "Pro Annual"
   - Price: $59.99
   - Subscription Group: "WorkoutApp Pro"
   - Introductory Offer: Free trial, 14 days (D-03)

Set the scheme to use this StoreKit Configuration: Xcode > Product > Scheme > Edit Scheme > Run > Options > StoreKit Configuration > select the file.

Note: In Xcode StoreKit sandbox, subscription durations are accelerated (1 month = 5 minutes). This is normal Apple sandbox behavior.
  </action>
