# Phase 7 — UI Design Contract

> Visual and interaction contract for Phase 7: Subscriptions and Paywall. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — iOS native (SwiftUI HIG) |
| Preset | not applicable |
| Component library | SwiftUI native views (no third-party component library); RevenueCat SDK for purchase logic only — no RevenueCatUI template components |
| Icon library | SF Symbols 5 (system icons bundled with iOS 17+) |
| Font | SF Pro (system default; no custom font) |

**Note:** This phase builds a fully custom SwiftUI paywall driven by RevenueCat's Offerings API. RevenueCatUI's pre-built `PaywallView` template is NOT used — the design requirements (blurred plan preview, "Most Popular" badge, pause→discount retention sequence) are incompatible with the generic template. All design tokens inherit from Phase 1 + Phase 2 with additions for paywall-specific states. (Source: RESEARCH.md Standard Stack + Alternatives Considered.)

---

## Spacing Scale

iOS HIG minimum touch target: 44pt. All values in SwiftUI points. Inherits Phase 1 + Phase 2 tokens unchanged.

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4pt | Gap between checkmark icon and value prop text, badge internal padding |
| sm | 8pt | Between pricing cards, between value prop rows |
| md | 16pt | Default horizontal content margin, pricing card internal padding |
| lg | 24pt | Section spacing within paywall (value props → social proof → pricing cards) |
| xl | 32pt | Horizontal edge padding on paywall body content |
| 2xl | 48pt | Vertical breathing room above first section (logo/headline area bottom margin) |
| 3xl | 64pt | Top safe area clearance on full-screen paywall modal |

Exceptions:
- CTA button height: 56pt (tall touch target for primary conversion action — wider than standard 44pt minimum to increase tap success rate on a conversion-critical button).
- "Most Popular" badge: 24pt height, 8pt horizontal internal padding, positioned absolutely top-right of the annual pricing card with a `-12pt` vertical offset to straddle the card edge.
- Pricing card minimum height: 88pt (content-driven; must not be fixed — allows Dynamic Type to expand without clipping).
- Pause chip height: 44pt (minimum touch target, also full HIG compliance for segmented-style chips).
- Fine print text area: `sm` (8pt) top margin below CTA, `xl` (32pt) horizontal inset — must be readable without scrolling on iPhone SE (minimum supported form factor).
- Blurred overlay on expired plan: blur radius 8pt applied via `.blur(radius: 8)` modifier on the plan preview content; semi-transparent scrim `#000000` at 40% opacity layered above blur.

## Typography

All sizes in SwiftUI points. Font: SF Pro (system default via `.font()` modifier). Dynamic Type required on all text. Inherits Phase 1 + Phase 2 two-weight, four-size constraint.

| Role | Size | Weight | Line Height | SwiftUI Token |
|------|------|--------|-------------|---------------|
| Body | 17pt | Regular (400) | 1.5 | `.body` |
| Label | 15pt | Regular (400) | 1.4 | `.subheadline` |
| Heading | 22pt | Semibold (600) | 1.2 | `.title2` |
| Display | 28pt | Semibold (600) | 1.1 | `.title` |

Phase 7 role assignments (no new sizes or weights introduced):

| Element | Size | Weight | Notes |
|---------|------|--------|-------|
| Paywall headline ("Your personalized plan is ready") | `.title` (28pt) | Semibold (600) | Display role — maximum visual impact on conversion screen |
| Plan name / pricing card main price label | `.title2` (22pt) | Semibold (600) | Heading role |
| Pricing card sub-label (e.g., "billed $59.99/year") | `.subheadline` (15pt) | Regular (400) | Label role |
| Value prop bullet text | `.body` (17pt) | Regular (400) | Body role |
| Social proof count ("Join 1,200 members") | `.subheadline` (15pt) | Regular (400) | Label role, `.secondary` color |
| "Most Popular" badge text | `.subheadline` (15pt) | Semibold (600) | Exception: Label size at Heading weight — acceptable for a short badge string |
| CTA button label ("Start 14-Day Free Trial") | `.body` (17pt) | Semibold (600) | Body size at Heading weight — standard iOS button pattern |
| Fine print below CTA | `.subheadline` (15pt) | Regular (400) | Label role, `.tertiary` color |
| Retention screen heading ("Life gets busy — take a break") | `.title2` (22pt) | Semibold (600) | Heading role |
| Retention screen body | `.body` (17pt) | Regular (400) | Body role |
| Pause chip labels ("1 month", "2 months", "3 months") | `.subheadline` (15pt) | Regular (400) | Selected state: Semibold (600) |
| Discount offer headline ("Stay for half price") | `.title2` (22pt) | Semibold (600) | Heading role |
| Post-purchase success heading ("You're all set") | `.title` (28pt) | Semibold (600) | Display role |
| Post-purchase success body | `.body` (17pt) | Regular (400) | Body role |

**Constraints (inherited from Phase 1):**
- Maximum 4 sizes: 15pt, 17pt, 22pt, 28pt. No additional sizes in this phase.
- Maximum 2 weights: Regular (400) and Semibold (600). No medium, bold, or italic.
- All text must use SwiftUI semantic font tokens — never `.system(size: N)` — so iOS accessibility Dynamic Type scaling works automatically.
- Trial period copy ("14-Day") must never be hardcoded as a string. Read from `package.storeProduct.introductoryDiscount?.subscriptionPeriod` at runtime and show trial copy only when the discount is non-nil. (Source: RESEARCH.md Pitfall 2.)
- Price strings must never be hardcoded. Always use `package.storeProduct.localizedPriceString`. (Source: RESEARCH.md Anti-Patterns.)

## Color

Inherits Phase 1 dark-mode-first fitness aesthetic. No new semantic hues introduced; two paywall-specific surface treatments added (pricing card selected state, blurred expired overlay).

| Role | Dark Mode | Light Mode | Usage |
|------|-----------|------------|-------|
| Dominant (60%) | `#0F0F0F` (near-black) | `#F5F5F5` (near-white) | Paywall modal background, retention screen backgrounds, post-purchase success screen background |
| Secondary (30%) | `#1C1C1E` (system grouped bg) | `#FFFFFF` (white) | Pricing card default (unselected) fill, pause chip unselected fill |
| Accent (10%) | `#FF6B35` (energetic orange) | `#FF6B35` (same) | See reserved list below |
| Destructive | `#FF3B30` (iOS system red) | `#FF3B30` (same) | "Cancel anyway" link text only |

**SwiftUI semantic mappings (inherited):**
- Dominant: `.systemBackground` / `Color("AppBackground")`
- Secondary: `.secondarySystemBackground` / `Color("CardBackground")`
- Accent: `Color("AccentColor")` — app accent color in Assets.xcassets
- Destructive: `Color.red` — "Cancel anyway" link text on DiscountOfferView

**Accent reserved for (Phase 7 additions):**
1. Selected pricing card border — 2pt stroke in `Color("AccentColor")`; unselected card uses 1pt stroke in `.tertiaryLabel`
2. Selected pricing card background fill — `Color("AccentColor")` at 10% opacity (`.opacity(0.10)`) over the dominant background
3. "Most Popular" badge — accent fill, white label text
4. Primary CTA button fill — `Color("AccentColor")` solid fill on "Start 14-Day Free Trial" and "Accept Offer" buttons
5. Selected pause chip — accent fill, white label
6. "Pause Membership" CTA button fill — `Color("AccentColor")` solid fill (primary action on retention screen 1)
7. Active tab bar item icon tint (inherited from Phase 1)

Accent is NOT used for: unselected pricing cards, unselected pause chips, fine print text, social proof count, retention screen body text, "I still want to cancel" link, card shadows, modal background, or any heading text.

**Pricing card selected state:**
- Border: 2pt, `Color("AccentColor")`
- Background: dominant surface + accent at 10% opacity overlay
- "Most Popular" badge: accent fill, `.white` text

**Pricing card unselected state:**
- Border: 1pt, `.tertiaryLabel` color
- Background: `Color("CardBackground")` (secondary)
- No badge

**Blurred expired plan overlay (BlurredPlanGateView):**
- Plan content: `.blur(radius: 8)` modifier
- Scrim: `Color.black.opacity(0.40)` layered above the blur
- "Your plan is waiting" copy: `.white` at full opacity, centered on overlay, `.title2` semibold
- Tapping anywhere on the overlay triggers `PaywallView` — no separate CTA button needed (D-15)

(Source: Accent `#FF6B35` from Phase 1 + Phase 2 UI-SPEC. All card states from CONTEXT.md D-08 + `<specifics>` block.)

## Screen Inventory

Phase 7 delivers exactly these screens/views:

| Screen | Type | Trigger |
|--------|------|---------|
| PaywallView | `fullScreenCover` modal | (a) Phase 3 plan preview "Start Training" CTA; (b) AppState gate: authenticated + onboarded + !isSubscribed; (c) tapping BlurredPlanGateView on expired state |
| BlurredPlanGateView | Inline overlay (not a separate screen) | Replaces plan content area when `isSubscribed == false` and user has completed onboarding |

| PauseOptionsView | First screen inside CancellationRetentionView stack | Initial state of retention flow |

No new tabs introduced. All flows are modals or Profile tab pushes.

## Interaction Contracts

### PaywallView — Subscription Paywall Modal

**Presentation:** `.fullScreenCover` — covers the entire screen. No drag-to-dismiss (hard paywall — no accidental dismissal). Dismiss only on successful purchase or explicit "Restore Purchases" link.

**Layout (top to bottom, within a vertical `ScrollView`):**

1. **Close/Restore row** — trailing: "Restore Purchases" `.subheadline` regular link (`.secondary` color). If user has not completed onboarding, no close button exists. After a successful purchase, the view self-dismisses.
2. **Headline** — "Your personalized plan is ready" — `.title` semibold, centered, horizontal padding `xl` (32pt).
3. **Value prop list (`ValuePropListView`)** — 3–4 checkmark bullet rows. Each row: leading `checkmark` SF Symbol (`.body` size, accent color) + body text. Rows spaced `sm` (8pt) apart. Horizontal padding `xl` (32pt). Content (source: CONTEXT.md D-05):
   - "AI plan built for you"
   - "500+ exercises with video"
   - "Coach chat anytime"
   - "Adapts as you improve"
4. **Social proof** — "Join 1,200 members" — `.subheadline` regular, `.secondary` color, centered. Start with seeded value of 1,200; update via Supabase `app_config` table — never derive from a per-load query. (Source: CONTEXT.md D-07 + RESEARCH.md Open Question 2.)
5. **Pricing cards (`VStack(spacing: 8)`)** — two `PricingCardView` instances:
   - Annual card (rendered first, pre-selected by default per D-08):
     - Top label: "Annual" — `.title2` semibold
     - Price label: "$4.99/month" — `.title2` semibold (from `package.storeProduct.localizedPriceString` divided computation — display only; actual charge is annual)
     - Sub-label: "billed $59.99/year · ~50% off" — `.subheadline` regular, `.secondary`
     - "Most Popular" badge: top-right, accent fill, white `.subheadline` semibold text, 12pt corner radius
     - Selected state: accent border + accent 10% fill
   - Monthly card (below annual):
     - Top label: "Monthly" — `.title2` semibold
     - Price label: "$9.99/month" — `.title2` semibold (from `package.storeProduct.localizedPriceString`)
     - No badge
     - Unselected by default
   - Cards are mutually exclusive; tapping one selects it and deselects the other. Selection stored in `PaywallViewModel.selectedPackage`.
   - Each card: 16pt corner radius, content padding `md` (16pt) all sides, minimum height 88pt.
6. **Primary CTA button** — full-width, 56pt height, accent fill, 14pt corner radius, white label.
   - Label (trial-eligible): "Start 14-Day Free Trial" — read eligibility from `package.storeProduct.introductoryDiscount` at runtime. Do not hardcode "14-Day."
   - Label (not trial-eligible): "Subscribe Now"
   - Loading state: `ProgressView()` centered in button, accent fill button remains, label hidden.
   - Horizontal padding `xl` (32pt).
7. **Fine print** — centered, `.subheadline` regular, `.tertiary` color. Content (selected annual): "Cancel anytime. $59.99/year after trial." — Content (selected monthly): "Cancel anytime. $9.99/month after trial." Fine print updates reactively when card selection changes.
8. **Bottom spacing** — `sm` (8pt) below fine print, plus safe area inset handled by `.safeAreaInset(edge: .bottom)`.

**Loading state (offerings not yet fetched):**
- Show skeleton: two pricing card `RoundedRectangle` placeholders in secondary color, animated with `.redacted(reason: .placeholder)`. CTA button is disabled (`.disabled(true)`), accent fill maintained at 50% opacity. Headline and value props visible immediately (static content — no skeleton needed).
- Offerings are pre-fetched by RevenueCat SDK on init and return from cache in most cases. Show loading state for maximum 500ms before forcing a UI update.

**Error state (offerings fetch failed):**
- Replace pricing cards with: `exclamationmark.triangle` SF Symbol (`.title2` size, `.secondary` color) + "Couldn't load pricing" label (`.subheadline`, `.secondary`) + "Try Again" button (`.subheadline`, accent color, `.plain` button style).
- CTA button hidden when in error state.

**Post-purchase success state:**
- Replaces all paywall content (in-place transition with `.transition(.opacity)`).
- Layout: `checkmark.circle.fill` SF Symbol (60pt, accent color) + "You're all set" heading (`.title` semibold) + "Your 14-day free trial has started. Enjoy the full app." body (`.body` regular) + "Start Training" button (accent fill, 56pt, same style as CTA).
- "Start Training" dismisses the `fullScreenCover` and routes to MainTabView.
- Trial period text is dynamic — same runtime check as CTA label.

### BlurredPlanGateView — Expired / Lapsed State

**Context:** Rendered over the plan preview area when `AppState.isSubscribed == false` after onboarding. The plan preview content renders at full fidelity beneath this view (to preserve rendering performance and demonstrate real content behind the gate).

**Layout:**
- `ZStack`: plan preview content (`.blur(radius: 8)`) as bottom layer, `Color.black.opacity(0.40)` scrim as middle layer, centered copy as top layer.
- Centered copy: "Your plan is waiting" — `.title2` semibold, `.white`, with a subtle `.shadow(color: .black.opacity(0.6), radius: 4)` for legibility on varied background content.
- No CTA button — entire overlay is tappable via `.onTapGesture { showPaywall = true }`.
- `.contentShape(Rectangle())` on the overlay ensures the entire surface area registers taps.

### CancellationRetentionView — Retention Flow Coordinator

**Presentation:** Pushed onto the Profile tab's `NavigationStack` when "Manage Subscription" is tapped. Not a modal — uses standard navigation push so the system back button is available if the user decides not to proceed.

**Navigation:** `NavigationStack` with `PauseOptionsView` as the root. `DiscountOfferView` is pushed when "I still want to cancel" is tapped. No custom navigation transitions — system default slide.

### PauseOptionsView — Retention Screen 1: Pause

**Layout (top to bottom):**
1. Navigation bar title: "Manage Subscription" — `.inline` display mode.
2. Heading: "Life gets busy — take a break" — `.title2` semibold, leading-aligned, horizontal padding `xl` (32pt), top padding `lg` (24pt). (Source: CONTEXT.md `<specifics>`.)
3. Body: "Pause your plan for a month or two and pick up right where you left off." — `.body` regular, `.secondary` color, horizontal padding `xl` (32pt), `sm` (8pt) top margin below heading. Line height 1.5.
4. **Pause chip selector** — horizontal `HStack(spacing: 8)` of 3 chips: "1 month", "2 months", "3 months". Each chip: 44pt height, horizontal internal padding `md` (16pt), 22pt corner radius (pill shape). Selected chip: accent fill, white label semibold. Unselected chip: secondary fill, `.label` color regular. Mutually exclusive selection. Top margin `lg` (24pt). Horizontal padding `xl` (32pt).
5. **Billing transparency notice** — "Pausing hides your plan in the app. Your billing continues — manage your subscription in Settings > Apple ID > Subscriptions." — `.subheadline` regular, `.secondary` color, horizontal padding `xl` (32pt), `sm` (8pt) top margin. **This copy is mandatory** — it explicitly communicates that "pause" is an in-app UX state and does not halt Apple billing. (Source: RESEARCH.md Open Question 1 — must appear in the UI to avoid misleading users.)
6. **"Pause Membership" CTA** — full-width, 56pt height, accent fill, 14pt corner radius, white label `.body` semibold. Label: "Pause for [N] month[s]" — updates reactively to selected chip. Disabled until a chip is selected. Horizontal padding `xl` (32pt), top margin `2xl` (48pt).
7. **"I still want to cancel" link** — `.body` regular, `.secondary` color, centered below CTA, top margin `md` (16pt). Tapping pushes `DiscountOfferView`.

**Pause action (on "Pause Membership" tap):**
- Record `subscription_pause_until = today + N months` in Supabase `profiles` via async call.
- On success: open Apple subscription management URL (`customerInfo.managementURL` — fallback: `https://apps.apple.com/account/subscriptions`) via `UIApplication.shared.open(_:)`.
- On error: show inline error below CTA in `.subheadline` `.secondary` "Something went wrong. Please try again." — no alert sheet.
- No spinner overlay — show inline loading in CTA: replace label with `ProgressView()`, keep button enabled visually but disabled functionally to prevent double-tap.

### DiscountOfferView — Retention Screen 2: Discount

**Presentation:** Pushed from `PauseOptionsView` when "I still want to cancel" is tapped. Back button navigates back to `PauseOptionsView` — standard system back.

**Layout (top to bottom):**
1. Navigation bar title: "Special Offer" — `.inline`.
2. Heading: "Stay for half price" — `.title2` semibold, leading-aligned, horizontal padding `xl` (32pt), top padding `lg` (24pt). (Source: CONTEXT.md `<specifics>`.)
3. Body: "Get 50% off for the next 3 months — $4.99/month, then $9.99/month." — `.body` regular, horizontal padding `xl` (32pt), `sm` (8pt) top margin. (Source: CONTEXT.md D-12. Price strings must read from the promotional offer object via RevenueCat SDK — hardcoded values shown here are display-intent only.)
4. Offer detail card — `RoundedRectangle` with secondary fill, 16pt corner radius, `md` (16pt) padding, containing:
   - "50% off" — `.title` semibold, accent color, centered.
   - "3 months, then full price" — `.subheadline` regular, `.secondary`, centered.
   - Top margin `lg` (24pt).
5. **"Accept Offer" CTA** — full-width, 56pt height, accent fill, 14pt corner radius, white `.body` semibold label. Horizontal padding `xl` (32pt), top margin `2xl` (48pt).
6. **"Cancel anyway" link** — `.body` regular, `Color.red` (destructive), centered below CTA, top margin `md` (16pt).

**"Accept Offer" action:**
- Call `Purchases.shared.promotionalOffer(forProductDiscount:product:)` then `Purchases.shared.purchase(package:promotionalOffer:)`.
- On success: pop the entire `CancellationRetentionView` navigation stack back to `ProfileView`. Show brief inline confirmation banner: "Offer applied. Enjoy 3 months at half price." — `.subheadline` semibold, accent color, appears at top of `ProfileView` for 3 seconds then fades.
- On error (offer unavailable, user ineligible): show `.body` `.secondary` inline message "This offer isn't available right now." — replace CTA with "Manage in Settings" button that opens `managementURL`.
- Loading: same pattern as PauseOptionsView CTA — replace label with `ProgressView()`.

**"Cancel anyway" action:**
- Open `managementURL` (Apple subscription management). No in-app confirmation alert — direct handoff to system settings is the standard App Store pattern. The color red on "Cancel anyway" signals destructive nature without needing an additional dialog.

**Note:** Per RESEARCH.md Assumption A4, the promotional offer is only valid for users with an active (non-trial) monthly subscription. This screen must only be reachable when the user has an active monthly subscription. The planner must add a guard to the routing logic: annual subscribers or trial users navigate directly to the management URL rather than seeing this screen.

## Accessibility Contract

- All interactive elements have `.accessibilityLabel` set.
- Pricing cards: `.accessibilityLabel("[Annual/Monthly] plan, [price display]")` + `.accessibilityAddTraits(.isButton)` + `.accessibilityValue(isSelected ? "selected" : "not selected")`.
- "Most Popular" badge: `.accessibilityLabel("Most Popular")` as a sibling label to the annual card, not a separate interactive element. Grouped with annual card via `.accessibilityElement(children: .combine)`.
- CTA button: `.accessibilityLabel("Start [N]-day free trial")` (or "Subscribe Now") — reads the full action intent, not just the button label.
- Pause chips: `.accessibilityLabel("[N] month pause")` + `.accessibilityAddTraits(.isButton)` + `.accessibilityValue(isSelected ? "selected" : "not selected")`.
- "I still want to cancel" link: `.accessibilityLabel("I still want to cancel")` — keep exact copy for VoiceOver users to understand the gravity of the action.
- "Cancel anyway" link: `.accessibilityLabel("Cancel subscription")` — more descriptive than "Cancel anyway" for VoiceOver context.
- Blurred overlay: `.accessibilityLabel("Your plan is waiting. Tap to subscribe.")` so VoiceOver users understand the gate and how to proceed.
- Fine print: `.accessibilityHidden(false)` — must be readable by VoiceOver (subscription terms are legally required to be accessible).
- Billing transparency notice on PauseOptionsView: `.accessibilityHidden(false)` — legally significant disclosure.
- Minimum touch target: 44pt × 44pt on all tappable elements. CTA buttons are 56pt height (exceeds minimum). Chips are 44pt height minimum.
- Dynamic Type: all text uses SwiftUI semantic font tokens. Paywall layout uses `ScrollView` so content reflows at larger text sizes without clipping.
- Color contrast: accent `#FF6B35` on `#0F0F0F` = 4.6:1 (WCAG AA). White text on accent button = 3.0:1 (meets WCAG AA for large text and UI components). Destructive `#FF3B30` on `#0F0F0F` = 4.7:1 (WCAG AA).
- "Cancel anyway" red link must not rely on color alone to signal destructive nature — placement (below the positive CTA, separated by margin) provides spatial context.
