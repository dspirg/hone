1. Create a 1024x1024 PNG of the Hone app icon in any design tool (Figma, Sketch, Photoshop, etc.)

   - Background: solid dark (#0a0a0a)

**Step 2: Verify archive build succeeds** (per D-15, SHIP-04)

Run the archive build command:
```bash
xcodebuild archive -scheme WorkoutApp -configuration Release -archivePath /tmp/WorkoutApp.xcarchive -destination 'generic/platform=iOS' CODE_SIGN_IDENTITY=- AD_HOC_CODE_SIGNING_ALLOWED=YES 2>&1
```

Note: `CODE_SIGN_IDENTITY=-` with `AD_HOC_CODE_SIGNING_ALLOWED=YES` allows building an archive without a distribution certificate for CI/local verification. The actual distribution signing happens when uploading via Xcode Organizer.

Check for:
- Build succeeds (exit code 0, "ARCHIVE SUCCEEDED" in output)
- No missing icon warnings (grep output for "icon" warnings)
- No privacy manifest warnings
- PrivacyInfo.xcprivacy is included in the archive bundle

If the archive fails, diagnose the error and fix. Common issues:
- Missing provisioning profile: automatic signing should handle this
- Missing icon: verify AppIcon-1024.png exists at the correct path
- Build errors: check for any code-level issues introduced
