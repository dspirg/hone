  <action>
    Create `Scripts/generate-app-icon.swift` — a standalone Swift script that uses CoreGraphics to generate the app icon. Run it with `swift Scripts/generate-app-icon.swift` to produce the PNG.

    The script must:

    1. Import Foundation and CoreGraphics (use `import CoreGraphics` and `import ImageIO` — these are available on macOS without additional frameworks).

    2. Create a 1024x1024 bitmap context:
       - Use `CGColorSpaceCreateDeviceRGB()` color space
       - Use `CGBitmapInfo.byteOrder32Big` with `CGImageAlphaInfo.noneSkipLast` (RGB, NO alpha per D-02)
       - 4 bytes per pixel, 4096 bytes per row

    3. Fill the entire canvas with dark background color #0a0a0a (RGB: 10/255, 10/255, 10/255) per D-01.

    4. Draw the "H" lettermark centered on the canvas:
       - The H should occupy approximately 55-60% of the icon dimensions (roughly 560-620px tall, proportionally wide)
       - Use a bold geometric sans-serif style (use system bold font at ~500pt via CTFont from CoreText)
       - Apply a linear gradient fill from #f59e0b (amber, RGB: 245/255, 158/255, 11/255) at top to #f97316 (orange, RGB: 249/255, 115/255, 22/255) at bottom per D-01
       - To achieve gradient text: create a text path using CTFontCreatePathForGlyph, then clip to that path and draw the gradient

    5. Write the CGImage to PNG at the output path `WorkoutApp/Assets.xcassets/AppIcon.appiconset/AppIcon-1024.png`:
       - Use CGImageDestinationCreateWithURL with kUTTypePNG
       - Verify the file was written successfully

    6. Print a success message with the output path and file size.

    After creating the script, run it:
    ```
    cd /Users/Fish/Desktop/workout && swift Scripts/generate-app-icon.swift
    ```

    Verify the output file exists and has reasonable size (should be 10KB-200KB for a 1024x1024 PNG with flat colors and gradient).

    If CoreText is needed for font access, add `import CoreText`. All these frameworks are available in macOS Swift without Xcode project setup.

    Design references per D-01: bold "H" lettermark inspired by Halide/Headspace — clean, brandable, distinctive. The gradient runs top-to-bottom (amber at top, orange at bottom).
