## Spacing Scale

Declared values from `Theme.Spacing` (all multiples of 4):

| Token | Swift name | Value | Usage |
|-------|-----------|-------|-------|
| xs | Theme.Spacing.xs | 4pt | Icon gaps, inline padding, dot spacing |
| sm | Theme.Spacing.sm | 8pt | Tight element spacing, streak-day gaps |
| md | Theme.Spacing.md | 16pt | Default padding (card horizontal, section gaps) |
| lg | Theme.Spacing.lg | 24pt | Section-to-section spacing |
| xl | Theme.Spacing.xl | 32pt | Layout-level vertical gaps |
| xxl | Theme.Spacing.xxl | 48pt | Major vertical breathing room |
| xxxl | Theme.Spacing.xxxl | 64pt | Page-level top/bottom margins |

Exceptions:
- Streak day tiles: 36x36pt touch target (≥ minimum readable size; not an interactive tap target)
- Emoji difficulty picker: 44pt emoji size — preserves touch target from existing implementation (D-11)
- Set check buttons (session): 44x44pt — Apple HIG minimum touch target
- Rep input box: 72x44pt — wider for digit readability
- Bottom CTA button: full width, 52pt height (existing pattern from SessionSummaryView)
- Screen-edge horizontal padding: 20pt (matches sketch default.css --space-5 = 20px)

## Typography

SwiftUI semantic type styles mapped to exact sizes (SF Pro, device default).

**Exactly 4 tiers, exactly 2 weights.**

| Tier | SwiftUI Style | Exact pt | Weight | Line Height | Usage |
|------|--------------|----------|--------|-------------|-------|
| Display | .largeTitle (.system(size: 34)) | 34pt | Bold (700) | 1.2 | Greeting "Hey Dan" — name span in accent color; stat ring values |
| Heading | .title2.weight(.semibold) or .title2.weight(.bold) | 22pt | Semibold/Bold (600–700) | 1.2 | Exercise name in session, card headings, "Great work.", plan name, stat pill values, context card values |
| Body | .body (.system(size: 17)) | 17pt | Regular (400) | 1.5 | Greeting sub-label, exercise count/duration row, streak label, secondary descriptors, session timer |
| Label | .caption (.system(size: 11)) | 11pt | Regular (400) or Semibold (600) | 1.3 | Stat pill labels, section labels (uppercase 0.08em tracking), streak day letters, context card labels, muted secondary captions |

Per-element assignments:

| Element | Tier | SwiftUI call | Notes |
|---------|------|-------------|-------|
| Greeting sub-label ("Good evening") | Body | `.body` | Regular 400, secondary color — collapsed from .subheadline 15pt |
| Greeting main ("Hey Dan") | Display | `.largeTitle.bold` | 34pt bold; name span in accent color |
| Exercise name in session | Heading | `.title2.weight(.semibold)` | 22pt semibold |
| Plan name in Home workout card | Heading | `.title2.weight(.bold)` | 22pt bold, left-aligned |
| Stat pill value | Heading | `.title2.weight(.bold)` | 22pt bold; accent color for primary stat |
| Context card (Previous/Best) value | Heading | `.title2.weight(.bold)` | 22pt bold — was .title3 20pt; consolidated to Heading tier |
| "Great work." completion heading | Heading | `.title2.weight(.semibold)` | 22pt semibold |
| Day label sub-copy "{DayLabel} complete" | Body | `.body` | Regular 400, secondary color |
| Stat pill label | Label | `.caption` | 11pt regular, secondary color |
| Section label ("TODAY'S WORKOUT" etc.) | Label | `.caption.weight(.semibold)` | 11pt semibold, uppercase, 0.08em tracking, muted color |
| Session set counter ("Set N of N") | Body | `.body` | Regular 400, secondary color — collapsed from .subheadline 15pt |
| Session elapsed timer | Body | `.body.weight(.semibold)` | 17pt semibold, tabular-nums, accent color — collapsed from .subheadline 15pt |
| Context card label ("Previous" / "Best") | Label | `.caption` | 11pt regular, muted color |
| Streak day letter | Label | `.caption` | 11pt regular |
| Exercise count · duration descriptor | Body | `.body` | Regular 400, secondary color |

Eliminated tiers (checker fix):
- `.subheadline` (15pt) — fully collapsed into Body (17pt) at .body weight. Affected elements: greeting sub-label, session set counter, session elapsed timer, exercise count row.
- `.title3` (20pt) — eliminated. Context card values promoted to Heading tier using `.title2.weight(.bold)` at 22pt.

Maximum font size tiers: **4** (Display 34pt / Heading 22pt / Body 17pt / Label 11pt). Maximum weights: **2** (Regular 400, Semibold/Bold 600–700).

## Color

All color tokens from `Theme.swift` (backed by asset catalog; dark mode forced):

| Role | Token | Hex (dark) | Usage |
|------|-------|-----------|-------|
| Dominant (60%) | Theme.background | #0a0a0a | Screen background — all three screens |
| Secondary (30%) | Theme.surface / Theme.surfaceElevated | #161616 / #1e1e1e | Cards, exercise card body, context cards, stat pills |
| Accent (10%) | Theme.accent | #f59e0b | See reserved-for list below |
| Destructive | Theme.destructiveRed | #f87171 | Session abandon confirmation only |
| Success | Theme.successGreen | #34d399 | Adaptation banner text, PR badge values |
| Border | Theme.borderSubtle | #1f1f1f | Card outlines, set row dividers, streak-day borders |

Accent (#f59e0b) reserved for:
1. Greeting name span ("Hey **Dan**")
2. "Start Workout" button — gradient fill (#f59e0b → #f97316), black text
3. "Complete Set" / "Next Exercise" / "Finish Session" CTA button — gradient fill
4. Active/done set number circle — fill background, black text
5. Exercise sets label in Home workout card ("3 × 8-10")
6. Session elapsed timer text
7. Best context card value text in session
8. Weekly streak bar: done-day tile fill; today-day tile border
9. Progress dots (done state) in session exercise navigation
10. Tab bar active item color

Accent is NOT used for: inactive states, secondary text, card backgrounds, borders, icons in non-active state.

Destructive accent (#f87171) reserved for: "End Session" / "Abandon Workout" confirmation dialog only.

## Screen Specifications

### Screen 1: HomeView (full rebuild, UI-04)

Layout (top to bottom, ScrollView):
```
NavigationStack (no title — inline greeting replaces nav title)
  ScrollView
    Greeting section         [padding: top 16pt, horizontal 20pt]
      Text: greeting-sub     [.body, secondary, "Good evening"]
      Text: greeting-main    [.largeTitle.bold, "Hey {Name}" — name in accent]
    AdaptationBannerView     [conditional — only when recent adaptation]
      horizontal 20pt        [success-green tinted bg, 1pt border rgba(52,211,153,0.15)]
    Section label: "TODAY'S WORKOUT"  [uppercase caption, muted, margin-top 24pt]
    WorkoutCard              [Theme.surface, radius 16pt, padding 20pt, border borderSubtle]
      Row: plan name + day number   [.title2.bold left + day# accent right]
      Row: exercise count · duration [.body secondary]
      ExerciseRowView × N    [divider between rows, not after last]
      "Start Workout" button [full-width, 52pt height, gradient fill, .body.bold, black text]
    Section label: "THIS WEEK"
    StreakCard               [Theme.surface, radius 16pt, padding 20pt]
      WeekStreakBar           [36x36pt tiles]
      Streak count text       [.body secondary, centered, margin-top 8pt]
    Section label: "QUICK STATS"
    StatPillRow              [HStack 3 pills, horizontal 20pt]
      StatPillView: Sessions  [accent value]
      StatPillView: Sets      [white value]
      StatPillView: PRs       [success-green value]
    bottom padding: 32pt
```

Empty state (no active plan after load):
- SF Symbol: figure.run, 48pt, secondary color
- Heading: "No workout scheduled" (.title2.weight(.semibold), primary)
- Subtext: "Your plan will appear here after onboarding." (.body, secondary)

Loading state: ProgressView() centered, padding-top 48pt (preserve existing pattern).

Error state (network/fetch failure loading Home data):
- SF Symbol: wifi.slash, 48pt, secondary color
- Heading: "Couldn't load your workout" (.title2.weight(.semibold), primary)
- Subtext: "Check your connection and pull down to retry." (.body, secondary)
- Pull-to-refresh triggers re-fetch (SwiftUI `.refreshable` on ScrollView)

Navigation: "Start Workout" button triggers `.fullScreenCover` presenting SessionView. No intermediate TrainView step (D-13).

### Screen 2: ExerciseCardView (modified, UI-05)

Layout change — video area:
- Aspect ratio: 2:1 (was 16:9) — `aspectRatio(2/1, contentMode: .fit)`
- Rounded corners: 16pt radius with `clipShape(RoundedRectangle(cornerRadius: 16))`
- Horizontal inset: 20pt (matches sketch `.compact-video` margin)
- Tap gesture: presents VideoOverlayView as `.fullScreenCover` (existing component)
- Tap affordance: SF Symbol "arrow.up.left.and.arrow.down.right" overlay, bottom-right corner, 20pt, white at 0.7 opacity

Exercise info row (below video, 12pt top padding):
- Exercise name: `.title2.weight(.semibold)`, left-aligned
- "Set X of N" counter: `.body`, secondary, right-aligned (same row, HStack spaceBetween)
- Muscle + equipment: `.body`, accent color, below name

Set rows: unchanged from existing SetLogRow pattern.

ContextCardView (new, below set rows, padding 20pt horizontal, 20pt top):
```
HStack(spacing: 8)
  ContextCard("Previous", value: previousReps ?? "—", valueColor: .primary)
  ContextCard("Best",     value: bestReps    ?? "—", valueColor: Theme.accent)
```
Each card: `Theme.surface`, radius 12pt, padding 12pt, border `borderSubtle`, centered text.
Empty state (no previous data): show "—" as value — no card hiding.

Context-aware CTA (from SessionView):
- Sets remain on current exercise: "Complete Set" (accent gradient)
- All sets done, more exercises remain: "Next Exercise" (surface background, primary text, accent border)
- Last exercise, all sets done: "Finish Session" (accent gradient)
Button: full-width, 52pt height, .body.bold, 20pt horizontal padding, 36pt bottom padding.

## Interaction Contracts

### Home → Session transition
- Trigger: "Start Workout" button tap
- Transition: `.fullScreenCover(isPresented:)` — slides up from bottom (SwiftUI default sheet-style)
- Dismissal: SwiftUI `dismiss()` environment action from Summary "Done" button — slides back down
- Post-dismiss: Home tab receives updated stats (streak bar, quick stats) via `@Observable` shared state

### Session tab navigation
- Exercise cards: horizontal swipe / ZStack card-slide with `.spring(response: 0.4, dampingFraction: 0.8)` animation (existing pattern — preserve)
- Progress dots: update in sync with current exercise index

### Compact video tap-to-expand
- Tap anywhere on 2:1 video area → `.fullScreenCover` presents `VideoOverlayView`
- Dismiss via existing VideoOverlayView close button

### Adaptation banner visibility
- Shown: when `AdaptationService` returned a rationale during this session or within the last 24 hours
- Hidden: when no recent adaptation (banner is never a permanent fixture)
- No animation on show/hide — simple conditional render

### Set completion
- Set check button tap → fills amber, logs to `viewModel.completedSets`
- All sets complete: CTA text changes from "Complete Set" to "Next Exercise" or "Finish Session"
- Transition uses `.animation(.default, value: ctaLabel)` on button label
