**SessionRepository.swift** -- add three methods after the existing `saveDifficultyRating` method (per D-07, RESEARCH Pattern 2):

1. `fetchUserSessionIds(userId: String) throws -> Set<UUID>` (private helper):
```swift
private func fetchUserSessionIds(userId: String) throws -> Set<UUID> {
    let request = CDSessionLog.fetchRequest()
    request.predicate = NSPredicate(format: "userId == %@", userId)
    request.propertiesToFetch = ["id"]
    let sessions = try context.fetch(request)
    return Set(sessions.compactMap { $0.id })
}
```

2. `fetchPreviousReps(exerciseName: String, excludingSessionId: UUID?, userId: String) throws -> Int?`:
- Fetch all CDSetLog entries, sort by completedAt descending
- Filter to matching exerciseName AND sessionId in `fetchUserSessionIds(userId:)` AND sessionId != excludingSessionId
- Group remaining by sessionId, take the first group (most recent session)
- Return max `repsLogged` from that group, or nil if no history

3. `fetchBestReps(exerciseName: String, userId: String) throws -> Int?`:
- Fetch all CDSetLog entries
- Filter to matching exerciseName AND sessionId in `fetchUserSessionIds(userId:)`
- Return max `repsLogged` across all matches, or nil if none
