# Requirements: AI Workout App

**Defined:** 2026-04-16
**Core Value:** A conversational AI personal trainer in your pocket — one that knows you, builds your program, coaches you through sessions, and evolves with you as you improve.

## v1 Requirements

### Authentication

- [ ] **AUTH-01**: User can create an account with email and password
- [ ] **AUTH-02**: User can log in and stay logged in across app sessions
- [ ] **AUTH-03**: User can reset their password via email link
- [ ] **AUTH-04**: User can sign in with Apple (required by App Store guidelines for social auth)

### Onboarding

- [ ] **ONBD-01**: User completes a conversational (chat-style) onboarding flow to capture fitness goals, experience level, and available equipment
- [ ] **ONBD-02**: Onboarding flow is 5 screens or fewer (reduces drop-off)
- [ ] **ONBD-03**: User sees an AI-generated personalized workout plan preview before being presented with the paywall

### AI Plan Generation

- [ ] **AIPL-01**: User receives a fully personalized weekly workout plan generated by AI from their onboarding profile
- [ ] **AIPL-02**: AI explains why each exercise was selected in the plan (coach rationale displayed)
- [ ] **AIPL-03**: User can ask the AI to regenerate or adjust their plan at any time
- [ ] **AIPL-04**: AI generates plans that adapt to the user's available equipment on any given day

### Exercise Library

- [ ] **EXRC-01**: Every exercise in the app has a sourced/licensed animatic-style instructional video
- [ ] **EXRC-02**: User can browse and search exercises by muscle group, equipment, and difficulty
- [ ] **EXRC-03**: User can view an exercise detail page showing the video, description, muscles worked, and form tips
- [ ] **EXRC-04**: Workout videos are cached locally on device for offline playback during sessions

### In-Session Experience

- [x] **SESS-01
**: User can watch the exercise animatic video and log completed reps and sets during a workout
- [ ] **SESS-02**: Automatic rest timer activates between sets with configurable duration
- [ ] **SESS-03**: Session tracking works fully offline; data syncs to server when internet is restored
- [x] **SESS-04
**: User sees a completion summary at the end of each workout showing what was accomplished

### AI Coach Chat

- [ ] **CHAT-01**: User can ask the AI coach any fitness-related question at any time
- [ ] **CHAT-02**: User can modify their workout plan by talking to the AI coach in natural conversation
- [ ] **CHAT-03**: AI coach has full context of the user's profile, goals, and workout history when responding
- [ ] **CHAT-04**: AI coach proactively sends check-in messages based on user activity and progress patterns

### Progress Tracking

- [x] **PROG-01
**: User can view a full history of all completed workout sessions
- [x] **PROG-02
**: User can see current streak and longest streak, plus weekly consistency score
- [ ] **PROG-03**: User is notified when they set a new personal record on an exercise
- [x] **PROG-04
**: User can view charts showing volume over time, workouts per week, and performance trends

### Subscriptions & Billing

- [ ] **SUBS-01**: App offers monthly and annual subscription plans; annual plan is pre-selected and offered at a discount
- [ ] **SUBS-02**: New users receive a free trial period (7 or 14 days) before billing begins
- [ ] **SUBS-03**: Paywall is presented after the user has seen their AI-generated workout plan preview
- [ ] **SUBS-04**: App displays a cancellation retention flow (offer to pause or apply discount) when user attempts to cancel

### Adaptive AI

- [x] **ADPT-01
**: User can rate workout difficulty after each session; AI adjusts the next workout based on the rating
- [ ] **ADPT-02**: AI automatically evolves the user's training plan over weeks as performance data accumulates
- [ ] **ADPT-03**: AI detects missed or skipped sessions and adapts the week's remaining plan accordingly

### Safety & Compliance

- [ ] **SAFE-01**: App includes a visible physician-consult disclaimer (required to avoid App Store Guideline 1.4.1 rejection)
- [ ] **SAFE-02**: AI coach includes safety guardrails — refuses to give advice that could substitute for medical diagnosis or treatment

## v2 Requirements

### Social & Community

- **SOCL-01**: User can share a completed workout to social media
- **SOCL-02**: User can participate in community challenges
- **SOCL-03**: User can view a friends' activity feed

### Advanced Features

- **ADVN-01**: Apple Watch companion app for session tracking from the wrist
- **ADVN-02**: HealthKit integration for automatic activity data sync
- **ADVN-03**: Nutrition tracking and meal planning AI suggestions
- **ADVN-04**: Video form check using device camera with AI feedback

### Monetization

- **MOTZ-01**: Coach add-on packages (specialized programs, e.g., marathon prep, postpartum)
- **MOTZ-02**: Referral program with subscription credits
- **MOTZ-03**: Family/couple plan pricing

## Out of Scope

| Feature | Reason |
|---------|--------|
| Android app | iPhone-first to maintain quality; cross-platform adds significant scope |
| Live video coaching with real trainers | AI-only for scalability and margin; human trainers don't scale |
| Social leaderboards / competitive features | Research shows ~70% of users find global leaderboards demotivating; personal progress comparisons only in v1 |
| Nutrition tracking | Separate product area; dilutes the workout coaching focus in v1 |
| On-device LLM | Apple Foundation Models quality not validated for fitness coaching at launch; revisit iOS 18+ |
| Group workout sessions | Real-time multi-user complexity; defer until community features are v2 priority |
